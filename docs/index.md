# G2 Peak View

Even Realities G2 向けの、山名・山稜ビューです。
現在地から見える山稜のシルエットと山の名前を、G2 の視界に線画で表示します。

- [プライバシーポリシー](privacy-policy.md)
- [Privacy Policy (English)](privacy-policy.en.md)
- [ソースコード](https://github.com/iinuma/g2peakview)

## 使い方

左右の向きはテンプルのスワイプで合わせます（G2 から方位を読み取れないため）。
知っている山を正面に見て、その名前を画面中央に合わせてタップすると、表示と景色がそろいます。
上下は G2 の傾きセンサーで追従できます。
